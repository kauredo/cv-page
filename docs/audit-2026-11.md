# November 2026 audit record

## Summary

A SvelteKit 3 portfolio at vascokf.com: prerendered pages, a CV in English and Portuguese, 17 project pages and one contact endpoint. The audit found a technically clean site. Its problems were mostly copy (title, role, followed links to the live products) and a few dead links. All of that shipped on 2026-11-17. What remains is a CI workflow, two Search Console checks and a modal rebuild that waits for its next edit.

## Shipped from the audit

- Language and alternates: `<html lang>` and hreflang on `/cv` and `/cv/pt`, dead GitHub links to private repos removed (#50).
- Docs: three identical agent docs collapsed into `AGENTS.md` with stale font and palette claims fixed (#49).
- Old static site moved to the `archive/old-site` branch, dead `/old/` line dropped from `robots.txt` (#54).
- Links to products that visitors cannot open dropped, including the analytics-hub card link (#55).
- Skip link and a label on the project search (#56).
- Full name and current role on the home page and CVs, `ProfilePage` JSON-LD on `/cv`, Lisbon and contact facts in the home text (#57).
- `llms.txt` and named AI crawlers in `robots.txt` (#58).
- Footer row linking the live products (#59). UpSpeech is left out by a recorded cross-link rule.
- Google Analytics without cookies (consent denied by default), `/privacy` page, `security.txt` (#61).
- Content-Security-Policy (#63), TODO note on the `security.txt` renewal and new outside services (#64).
- Rate limit on `POST /api/contact` set in the Vercel Firewall (5 per minute per IP), checked live: the sixth post gets a 429. Not in the repo, so it is not visible in the code.
- Smaller fixes: autocomplete tokens on the contact form, `color-scheme` on the dark root, unused `svelte-inview` dependency and two unused images removed.
- Print layout of both CVs checked on 2026-11-16: two A4 pages each, no gaps.

## Open work

- CI that runs type check, lint and build: [plans/001-ci-check-lint-build.md](../plans/001-ci-check-lint-build.md). The repo is public, so Actions minutes are free. Use `yarn run check`: in Yarn 1, `yarn check` is a built-in command and not the project script.
- Cadence Studio card still links to a `vercel.app` host. The analytics-hub half is done (#55). No plan: it waits for a domain (see Waiting on).

## Waiting on

- Search Console name-query check: does the site rank for the owner's name? An earlier US-only tool run found nothing in the first 20 results for category queries, which is weak evidence. The owner reads the performance report for name queries.
- Portuguese home page and hreflang for Portuguese recruiter searches: the same report, filtered by country and language. Build nothing until it shows Portuguese recruiters arrive through search.
- Cadence Studio card link: waits until Cadence Studio has a real domain.
- Modal rebuild on native `<dialog>`: `Modal.svelte` is 253 lines and has no inert background or real focus trap. The decision is to do it the next time the modal is touched, so it has no plan. A `<dialog>` version would delete about 60 lines.

## Decide

- Whether Cadence Studio gets a real domain. The audit's recommendation: only if its search equity matters.
- Making the CI check required in branch protection once plan 001 has run green.

## Won't do, and why

- Sitemap `lastmod` from real dates for static pages: small payoff for the effort.
- Filter dropdown on `popover`: about 15 lines, and positioning needs anchor positioning, which has limited browser support.
- Keeping `<html lang>` right on client-side navigation between `/cv` and `/cv/pt`: direct loads and prerendered HTML are right, and the content div carries `lang`.
- Tests for the audit fixes: there is no test runner, and adding one was not judged worth it.
- A "now" or "writing" page: sounded good, no payoff shown.
- JSON Resume at `/cv.json`: sounded good, no demand.
- A build-time check that fails on 4xx or 5xx project links, and a "live" status per card: needs CI first. Revisit after plan 001 lands.
